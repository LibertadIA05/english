# Tea Time · Anglais A1

App web (mobile d'abord) pour apprendre l'anglais niveau A1, façon jeu.

- 10 unités, 40 leçons de ~5 min : se présenter, nombres, famille, restaurant, heure, courses, aéroport et hôtel, directions, loisirs, météo.
- Exercices : nouveau mot, QCM, paires, phrase à construire, dictée, écoute, saisie, phrase à trous, prononciation (micro).
- Correction tolérante (majuscules, ponctuation, contractions, petites fautes de frappe).
- Pas de vies, pas de pub, pas de notifications.
- Révision des erreurs par répétition espacée.
- Série de jours (1 jour de repos par semaine), objectif quotidien, XP, niveaux, statistiques.
- Fonctionne hors ligne et s'installe sur l'écran d'accueil. Progression enregistrée sur l'appareil (export/import possible).

Aucune dépendance, aucun build : `index.html`, `styles.css`, `data.js` (contenu du cours), `app.js`, `sw.js`.
Pour l'essayer en local : `python3 -m http.server` puis ouvrir http://localhost:8000.
